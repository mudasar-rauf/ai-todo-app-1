# Todo

A todo app built with Vite, React 19, TypeScript and the Astryx design system (theme-neutral).

## Prerequisites

- Node.js 20.19+ or 22.12+ (Vite 8's requirement) and npm

## Setup

```bash
npm ci
npx playwright install chromium   # browser for npm run test:e2e; writes nothing to the repo
```

## Scripts

| Script | Command | What it does |
|---|---|---|
| `npm run dev` | `vite` | Dev server on http://localhost:5173 |
| `npm run build` | `tsc -b && vite build` | Type-checks, then builds to `dist/` |
| `npm run preview` | `vite preview` | Serves `dist/` on http://localhost:4173 |
| `npm run typecheck` | `tsc -b` | Type-checks the app and the config files |
| `npm run lint` | `oxlint --react-plugin ...` | Lints with oxlint (the Vite template's linter) |
| `npm test` | `vitest run` | Unit and component tests (Vitest, jsdom, Testing Library, jest-dom matchers) |
| `npm run test:e2e` | `playwright test` | End-to-end tests in `e2e/`, against `npm run build && npm run preview`, on Desktop Chrome and Pixel 7 |

Vitest settings live in the `test` block of `vite.config.ts`; `src/test/setup.ts` loads the jest-dom matchers. Test globals (`describe`, `it`, `expect`) are on.

## Astryx

- **Themes module:** `src/astryx-themes.ts`, generated by `npx @astryxdesign/cli theme add neutral`. Do not edit it by hand. App code gets the theme only through it (`themes`, `defaultThemeSlug`), never by importing `@astryxdesign/theme-neutral` directly.
- **Agent docs:** `AGENTS.md` and `GEMINI.md`, written by `npx @astryxdesign/cli init`.
- Check the setup: `npx @astryxdesign/cli doctor`
- Read a component's import path and props before using it: `npx @astryxdesign/cli component <Name>`

The shell's contract (theme wiring, global CSS, frame components, file ownership) is [docs/contracts/shell.md](docs/contracts/shell.md).
